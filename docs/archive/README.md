# Documentation archive

This directory preserves superseded specifications, completed implementation records, release evidence, and deferred concepts. Archived documents are historical evidence, not current instructions. Current contributor and operating requirements are maintained in [AGENTS.md](../../AGENTS.md), the [project README](../../README.md), and [third-party notices](../../THIRD_PARTY_NOTICES.md). Original checkpoint text may still say work or release is pending; archiving does not assert acceptance, deployment, indexing or legacy-object retirement.

The [archive manifest](archive-manifest.json) records each adopted or release-owned item's original source path, archive path, status, successor, archival date, and body hashes.
